# Dilution and Injection Optimization for Untargeted Metabolomics of Isolated Mitochondrial Samples
This repository contains the code, data, Bayesian models, and generated outputs accompanying the manuscript:

**Bayesian Hierarchical Modeling for the Optimization of Dilution Factor and Injection Volume in Untargeted Metabolomics of Isolated Mitochondrial Samples**

The aim of the project is to optimize dilution factor and injection volume for untargeted metabolomics analysis of isolated mitochondrial samples measured with LC-QTOF-MS. A design-of-experiments framework was combined with Bayesian hierarchical modelling to evaluate how dilution factor and injection volume affect signal intensity, residual variability, sensitivity, and precision across metabolic features.

## Important note on model versions

The model described in the manuscript is **model 2**.

The main rendered analysis report for this manuscript model can be opened here:
[model 2 analysis report](https://margotbiesemans.github.io/dilution_injection_optimization/code/mitochondria_injection_dilution_optimization_mod2.html)

Other model versions are retained in the repository for development history and comparison, but model 2 is the model described in the manuscript above.

##Data

The raw input data are stored in:

data/rawdata/

The two raw data files correspond to positive and negative ionization modes:

data/rawdata/mito_dilop_stand_pos.csv
data/rawdata/mito_dilop_stand_neg.csv

Derived datasets generated during the analysis are stored in:

data/derived/

### Model output files

The fitted model output files are stored in:

model/model2/model-output/

The generated-quantities output files are stored in:

model/model2_gq/model_gq-output/
model/decision2_gq/decision_gq-output/

These output files are generated by running the Stan models and may be large. Hence, they are excluded from this GitHub repository. The output files can be generated by running the provided code.

## Running the analysis

Set up your RStudio project.

Then open the model 2 Quarto document:

code/mitochondria_injection_dilution_optimization_mod2.qmd

Our rendered report is available as:

code/mitochondria_injection_dilution_optimization_mod2.html

To reproduce the full analysis, run the Quarto document section by section. Computationally intensive model-fitting and generated-quantities chunks may need to be run manually depending on local computing resources.
