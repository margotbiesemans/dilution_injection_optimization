# Dilution and Injection Optimization for Untargeted Metabolomics of Isolated Mitochondrial Samples
This repository contains the code, data, Bayesian models, and generated outputs accompanying the manuscript:

**Bayesian Hierarchical Modeling for the Optimization of Dilution Factor and Injection Volume in Untargeted Metabolomics of Isolated Mitochondrial Samples**

The aim of the project is to optimize dilution factor and injection volume for untargeted metabolomics analysis of isolated mitochondrial samples measured with LC-QTOF-MS. A design-of-experiments framework was combined with Bayesian hierarchical modelling to evaluate how dilution factor and injection volume affect signal intensity, residual variability, sensitivity, and precision across metabolic features.
