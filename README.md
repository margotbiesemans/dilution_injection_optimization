# Welcome
This repository contains the data, R code, and Stan code used in "Bayesian Hierarchical Modeling for the Optimization of Dilution Factor and Injection Volume in Untargeted Metabolomics of Isolated Mitochondrial Samples" article.

The scripts folder includes the Quarto documents, which can be viewed here: https://margotbiesemans.github.io/dilution_injection_optimization/code/mitochondria_injection_dilution_optimization_mod2.html
